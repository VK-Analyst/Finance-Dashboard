# Product Analysis Report

## Problem Statement

Your manager has requested an executive summary report on the latest sales figures. Specifically, the manager wants to know the following key insights:

- **Which month and year had the most profit?**
- **Where is the company seeing the most success (by country/region)?**
- **Which product and segment should the company continue to invest in?**

## Steps to Complete the Task

### 1. Download and Understand the Dataset
- Obtain the latest sales dataset provided by the company.
- Review and understand the structure of the dataset, including the available columns and data points.

### 2. Import Data into Power BI Desktop
- Import the dataset into Power BI Desktop for further analysis.

### 3. Clean and Transform the Data
- Clean the data to ensure there are no missing values, duplicates, or errors.
- Transform the data as needed for analysis, including formatting and converting columns.

### 4. Create a Calendar Table
- Develop a calendar table for time-based analysis (e.g., monthly, yearly trends).

### 5. Prepare the Model
- Define relationships between tables to ensure accurate data representation and analysis.

### 6. Create Calculated Columns and Measures Using DAX
Use DAX to create the following calculated columns and measures:
- **Gross Sales Per Order**
- **Net Sales Per Order**
- **Profit Per Order**
- **Total Sales**
- **Total Profit**
- **Total Orders**
- **Total Units Sold**

## Analysis – Executive View

### 1. Create Year & Month Slicers
- Add slicers for year and month selection to allow the user to filter the data by time.

### 2. Chart: Profit by Month & Year
- Create a chart that displays the monthly and yearly profit trends, identifying the month and year with the highest profit.

### 3. Profit by Location
- Develop a visual to display the profit by country or region, highlighting areas of greatest success.

### 4. Sales by Product & Segment
- Create a chart or table that shows sales data by product and segment, helping to identify which products and segments are performing the best.
